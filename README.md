# Monotone-light factorization

This repository is the scoped public review mirror for an Isabelle/AFP
formalization of monotone-light factorization and uniqueness for continuous
maps from compact Hausdorff spaces to Hausdorff spaces.

The established human author team is Arthur Freitas Ramos, David Barros Hulak,
and Ruy Jose Guerra Barretto de Queiroz. AI assistance and independent AI
mathematical review will be disclosed with the source and validation artifacts.

The verified formalization is being prepared on the `verified-formalization`
review branch. Submission to AFP or Palomar requires Arthur's later approval.
